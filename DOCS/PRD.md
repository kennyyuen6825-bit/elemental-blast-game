# 產品需求文檔 (PRD) - Elemental Blast

## 1. 項目概覽
- **遊戲名稱**: Elemental Blast (元素爆破)
- **遊戲類型**: 益智 / 方塊消除
- **平台**: 手機 (iOS/Android)
- **盈利模式**: 廣告支持（插屏廣告、激勵影片）、內購（去廣告、皮膚）

## 2. 核心玩法
- **目標**: 將隨機生成的方塊形狀放置在 8x8 的網格上，通過填滿整行或整列來消除它們並獲得分數。
- **關鍵機制**:
    - **元素方塊**: 特定方塊具有元素屬性（火、水、風、土）。
    - **連鎖反應**: 消除含有元素的行/列會觸發特殊效果。
    - **遊戲結束**: 當網格上無法再放置任何生成的方塊時，遊戲結束。

## 3. 元素效果與戰鬥系統
- **火 (進攻型)**: 在消除的行周邊產生 3x3 的爆炸，即使沒有成線的方塊也會被清除。
- **水 (策略型)**: 凍結「連擊計時器」3 個回合，並「洗刷」掉 2 個阻礙空間的隨機孤立方塊。
- **風 (功能型)**: 額外消除一條隨機的行/列，並獲得一次「更換 (Swap)」次數（允許更換當前 3 個形狀中的一個）。
- **土 (防禦/加成型)**: 強化消除區域，下次在同一位置消除時分數翻倍。
- **雷 (稀有/終極效果)**: 清除當前版面上所有特定顏色或元素的方塊。

## 4. 進度系統與長期參與
- **元素升級**: 玩家在遊戲過程中收集「元素碎片」來升級效果（例如：2 級火元素爆炸範圍擴大至 5x5）。
- **關卡模式 (任務制)**: 除了無盡模式外，增加具有特定目標的關卡（例如：「消除 20 個火屬性方塊」、「在 2 分鐘內達到 5000 分」）。
- **每日挑戰**: 具有預設「冰凍方塊」的獨特網格佈局，必須先將其消除。

## 5. 盈利策略 (深度規劃)
- **激勵影片廣告**:
    - **復活**: 棋盤滿了時提供一次復活機會。
    - **刷新**: 重新隨機生成當前的 3 個方塊形狀。
    - **雙倍獎勵**: 在遊戲結束時觀看廣告，使收集的碎片翻倍。
- **內購 (IAP)**:
    - **新手禮包**: 去廣告 + 500 碎片 + 專屬「黃金之土」皮膚。
    - **皮膚/主題**: 賽博朋克、古代遺跡、星際星雲（改變視覺效果與音效）。
- **插屏廣告**: 每 3-4 場遊戲或返回主選單時顯示。

## 6. 視覺風格
- 簡潔、霓虹極簡主義 or 充滿活力的「元素」主題。
- **觸覺回饋**: 放置方塊時有輕微震動，消除時有強烈震動。
- **視覺特效 (Visual Juice)**: 火元素爆炸時屏幕抖動，水元素消除時有漣漪效果。

## 7. 技術棧 (建議)
- **引擎**: Unity (C#) 或 Godot (GDScript)。
- **目標解析度**: 1080x1920 (直向)。
