# 視覺設計與素材提示詞 (Design Prompts)

作為 AI 助手，我可以為你提供高度優化的提示詞。你可以將這些提示詞用於 **Midjourney**、**DALL-E 3** 或 **Stable Diffusion** 等工具來生成專業的遊戲素材。

## 1. 應用圖標 (App Icon) 提示詞
> **Prompt (英文)**: A high-quality, 3D isometric app icon for a mobile game. A glowing crystalline puzzle block with elemental fire and water swirling inside. Vibrant neon colors, dark background, polished glass texture, Apple App Store style. --v 6.0
> 
> **中文說明**: 高質量的 3D 等軸測手機遊戲圖標。一個發光的晶體方塊，內部有火與水元素旋轉。鮮豔的霓虹色，深色背景，拋光玻璃質感，蘋果 App Store 風格。

## 2. 元素方塊組 (Block Set)
> **Prompt (英文)**: A sprite sheet of 2D game puzzle blocks, isometric view. 4 variations: Fire (glowing red magma), Water (translucent blue liquid), Wind (ethereal white swirls), Earth (rugged green stone). Stylized casual game art, clean edges, high resolution.
> 
> **中文說明**: 2D 遊戲方塊素材表，等軸測視角。包含 4 種變化：火（發光的紅色岩漿）、水（半透明藍色液體）、風（空靈的白色旋渦）、土（粗糙的綠色石頭）。風格化休閒遊戲美術，邊緣整潔，高解析度。

## 3. 遊戲背景 (Background)
> **Prompt (英文)**: Abstract dark blue gradient background for a mobile puzzle game. Subtle geometric patterns, tech-noir aesthetic, high contrast, minimalist, vertical orientation.
> 
> **中文說明**: 用於手機益智遊戲的抽象深藍色漸變背景。細微的幾何圖案，科技黑幫美學，高對比度，極簡主義，垂直構圖。

## 4. UI 佈局構思
- **頂部欄 (Top Bar)**: 顯示當前分數、最高分和連擊倍率 (Combo Multiplier)。
- **中心區域**: 帶有微光的 8x8 網格。
- **底部區域**: 3 個放置待用方塊形狀的槽位。
- **頁腳 (Footer)**: 設置 (Settings) 與商店 (Shop) 按鈕。
