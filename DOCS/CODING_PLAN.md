# Elemental Blast 開發計畫 (Coding Plan)

這個計畫將開發過程分為五個階段，每個階段都可以獨立執行並測試。

## 階段 1：核心框架與基礎邏輯 (Core Framework)
- [ ] **1.1 網格系統 (Grid System)**：建立 8x8 陣列，處理方塊的放置與座標轉換。
- [ ] **1.2 方塊形狀生成 (Shape Generator)**：實作隨機生成 3 個一組的方塊形狀邏輯。
- [ ] **1.3 放置與碰撞判定 (Placement Logic)**：確保方塊只能放在空位，且拖拽手感流暢。
- [ ] **1.4 消除檢查 (Line Clearing)**：偵測整列或整行填滿，並執行消除。

## 階段 2：元素系統與特效 (Elemental Mechanics)
- [ ] **2.1 元素屬性分配**：為方塊隨機分配 火/水/風/土 屬性。
- [ ] **2.2 火元素 (Fire)**：實作 3x3 爆炸效果。
- [ ] **2.3 水元素 (Water)**：實作 Combo 凍結與隨機清理孤立方塊。
- [ ] **2.4 風元素 (Wind)**：實作額外消除與「換牌 (Swap)」功能。
- [ ] **2.5 土元素 (Earth)**：實作分數加倍區域邏輯。

## 階段 3：遊戲循環與 UI (Game Loop & UI)
- [ ] **3.1 計分系統 (Scoring)**：基礎得分、連擊得分與元素加成。
- [ ] **3.2 遊戲狀態管理**：開始介面、遊戲中、Game Over 判定、暫停。
- [ ] **3.3 基礎 UI 搭建**：分數顯示、最高分、下方 3 個方塊槽位。
- [ ] **3.4 資源載入**：串接由 AI 生成的圖片素材與音效。

## 階段 4：數值平衡與進度系統 (Progression & Balancing)
- [ ] **4.1 難度曲線設計**：隨著分數提高，出現更難放置的形狀。
- [ ] **4.2 升級系統 (Upgrades)**：消耗碎片提升元素威力的邏輯。
- [ ] **4.3 任務/關卡系統**：實作特定目標（如消除 10 個火方塊）的判定。

## 階段 5：盈利與上架準備 (Monetization & Release)
- [ ] **5.1 廣告 SDK 整合**：串接 AdMob/AppLovin (插屏與激勵影片)。
- [ ] **5.2 內購功能 (IAP)**：去廣告、購買碎片、皮膚解鎖。
- [ ] **5.3 效能優化與測試**：確保在低階手機上也能流暢運行。
- [ ] **5.4 多語系支持 (Localization)**：支持中英文切換。
